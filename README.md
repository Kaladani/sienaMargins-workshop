# Interpreting Model Estimates: Marginal Effects in RSiena

### 📖 **[Read it here](https://kaladani.github.io/sienaMargins-workshop/)**

Workshop material on reporting SAOM results on the probability scale: why a
coefficient is not an effect size, what a marginal effect has to become for a
model whose decisions are unobserved, and how to compute one — worked through on
a single network, then across 17 school classes.

Written for the EUSN 2026 workshop and extended so it can be read on its own.
Chapters 3 to 5 are executable: open the `.qmd` files in RStudio and run them.

Daniel Gotthardt (Hamburg), Christian Steglich (Groningen / Linköping),
Marijtje van Duijn (Groningen).

---

**Requires** the `sienaMargins` branch of RSiena:
`remotes::install_github("stocnet/rsiena@sienaMargins")`

**Data** are not included — see [`data/README.md`](data/README.md) for where to
get them and on what terms.
